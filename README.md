# 2 m² — la salle de sport qui tient chez toi

Site d'affiliation statique. Le contenu est dans `content.py`, le style dans `src/style.css`.

- Générer le site : `python3 build.py` (sortie dans `docs/`, publiée par GitHub Pages)
- Ajouter un guide : copier un bloc de `GUIDES` dans `content.py`, puis relancer le build
- Avant la mise en ligne : remplacer `base_url` et `amazon_tag` dans `content.py`
